TRIP PAY PWA 패키지

구성:
- index.html: 앱 본체
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 앱 파일 오프라인 캐시
- icons/: 앱 아이콘

설치 방법:
1. 이 폴더의 파일을 HTTPS를 지원하는 정적 웹 호스팅에 업로드합니다.
2. Android Chrome에서 업로드된 주소를 엽니다.
3. 최초로 페이지가 완전히 로드되도록 기다립니다.
4. Chrome 메뉴(⋮)에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
5. 설치 후 한 번 실행해 캐시가 완료되면 이후 인터넷 없이 사용할 수 있습니다.

주의:
- PWA 설치는 file:// 로컬 HTML 파일만으로는 정상 지원되지 않습니다.
- HTTPS 주소가 필요합니다.
- 여행 기록은 해당 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제 전 앱의 백업 기능을 사용하세요.
- 앱을 업데이트할 때는 호스팅된 파일을 교체하고 앱을 다시 열어 업데이트를 적용하세요.
